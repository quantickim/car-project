# 중고차 시세 분석

엔카(api.encar.com) 실매물로 관심 차종의 매물 검색, 시세 차트, **고출력 차량의 가치 방어(잔존율) 추천**을 보여주는 React + TypeScript + SCSS 앱.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

엔카 API는 CORS를 막기 때문에 로컬에서는 **Vite 서버(`dev` 또는 `preview`)로 실행**해야 합니다. `/encar-api` 프록시가 엔카를 대신 호출합니다. 같은 Wi-Fi의 휴대폰에서는 터미널에 표시되는 `Network:` 주소로 접속합니다.

## GitHub Pages 배포판

https://quantickim.github.io/car-project/

엔카는 해외 IP(GitHub Actions 포함)의 요청을 차단합니다. 그래서 배포판은 **국내 PC에서 수집한 데이터**를 씁니다.

```bash
npm run publish:data   # 엔카 수집 → data/listings.json·history.json 커밋 → 푸시 → Actions가 Pages 배포
```

배포판은 수집 시점 데이터로 동작합니다(헤더에 기준 시각 표시). 엔카 분류 조회가 필요한 '차종 추가'는 로컬 서버에서만 됩니다.

## 화면

| 탭 | 기능 |
|---|---|
| 가치방어 추천 | 최소 마력 이상 차종을 3년/5년 예상 잔존율 순으로 정렬. 3년 잔존율 80% 이상 + 신뢰도 보통 이상이면 '추천' |
| 매물 검색 | 출력·제로백·가격·연식·주행거리 조건으로 위시리스트 매물 검색. '시세 대비'는 같은 차종·같은 연식 중앙값과 비교 |
| 찜 목록 | ♡ 로 담은 매물 (브라우저 저장) |
| 시세 분석 | 연식별 시세(중앙값 + 중간 50% 구간), 주행거리-가격 분포, 날짜별 시세 추이 |
| 차종 관리 | 엔카 분류(제조사 → 모델 → 세대 → 연료/구동 → 트림)를 골라 관심 차종 추가 |

## 잔존율 계산 방식

1. 차종의 같은 세대·트림 매물을 모두 가져옴 (리스·렌트 승계 매물, 사진이 같은 중복 매물 제외)
2. `ln(가격) = a + b × 차령` 을 **Theil–Sen 회귀**(점 쌍 기울기의 중앙값, 차령 1년 이상 차이 나는 쌍만)로 적합 → 이상치 제거 후 재적합
3. `exp(b)` = 1년 지날 때 남는 가치 비율, 3년 잔존율 = `exp(b)³`, 5년 = `exp(b)⁵`
4. 트림 매물이 부족하면 `peerKeyword`(예: CLE53 → 카브리올레 포함)로 유사 트림까지 넓혀 추정

지금 시점의 "3년 더 오래된 같은 차" 가격으로 3년 뒤 가격을 추정하는 **횡단면 추정**이라 세대 변경, 환율, 시장 변화는 반영되지 않습니다.

### 실측 시세 추이 쌓기

엔카는 과거 시세를 제공하지 않으므로 날짜별 스냅샷을 `data/history.json` 에 직접 기록합니다.

- 추천 탭에서 분석할 때마다 자동 기록 (하루 한 건, 같은 날은 덮어씀)
- 시세 분석 탭의 '오늘 시세 기록' 버튼
- `npm run snapshot` — 서버 없이 기본 카탈로그 전체 기록
- `npm run publish:data` — 기록 + 배포판 데이터 갱신·푸시. 매일 실행하면 배포판의 시세 추이도 쌓입니다

기록이 7일 이상 쌓이면 추천 표의 '실측 변동'에 같은 연식 매물 기준 실제 변동률이 표시됩니다.

## 구조

```
src/
  api/encar.ts        엔카 쿼리 빌더 · 검색 · 분류 조회 (브라우저/Node 공용)
  data/catalog.ts     test.txt 기반 기본 차종 + 엔카 분류 매핑
  lib/analysis.ts     연식별 시세, 감가 추정, 등급
  lib/history.ts      시세 스냅샷
  pages/              탭별 화면
  components/charts/  Recharts 차트
  styles/             SCSS (토큰 · 라이트/다크)
server/historyStore.ts  /api/history (dev/preview 서버 미들웨어)
scripts/snapshot.ts     npm run snapshot
```

## 참고

- 엔카는 짧은 시간에 요청이 몰리면 429를 반환합니다. 클라이언트는 동시 2건으로 제한하고, 429 시 재시도하며, 결과를 30분간 세션에 캐시합니다.
- 840i 쿠페는 엔카에 분류가 없어 840i 그란쿠페 시세로 대체했습니다.
- 마력이 test.txt에 없는 차종(RS e-tron GT, e-tron GT, M850i, CLE53 등)은 국내 제원 값을 넣었습니다.
